# Frontend Custom Hooks

> Inventory of every reusable hook under `src/hooks/` (including the PDF-export hooks under `src/hooks/PdfDownload/`): purpose, inputs/outputs, a short usage example, and where each is used.

## Purpose

Serves as the reference catalog of the custom hooks in `insurance-policy-claim-management-app-ui`. Before writing a new list, form, or pagination page, engineers should check here first — most of the pattern already exists. Companion to [`Component_Architecture.md`](Component_Architecture.md) and [`State_Management.md`](State_Management.md).

## Overview

The hooks split into four families:

- **Context accessors** — `useAuth`, `useTheme` (thin `useContext` wrappers that throw if used outside a provider).
- **Server-driven data** — `useApiTable`, `useApiForm` (API-backed list and form orchestration).
- **Client-side utilities** — `useClientPagination`, `useSearch`, `usePagination`, `useTableState`, `useDebounceFilters`, `useDocumentTitle`.
- **PDF export** — `useClaimPdf`, `useCustomerPdf`, `usePaymentPdf`, `usePolicyPdf` (jsPDF + autotable report generators).

Additionally, `src/common/BentoCard.jsx` is a shared presentational component (not a hook) used on dashboards to render titled cards with an optional "View all" link.

## Technical Design

### Context accessors

**`useAuth`** — `src/hooks/useAuth.js`
- Returns the `AuthContext` value: `{ token, user, isAuthenticated, isRestoring, login, logout }`.
- Throws `"useAuth must be used inside <AuthProvider>"` if no context.
- Used by guards (`src/App.jsx`), `UnifiedLayout`, `Sidebar`, `TopNavbar`, `GlobalApiHandler`, and the PDF hooks (for "generated by").

```jsx
const { user, logout } = useAuth();
```

**`useTheme`** — `src/hooks/useTheme.js`
- Returns `{ theme, toggleTheme }` from `ThemeContext`; throws outside `<ThemeProvider>`.
- Same pattern as `useAuth`; component `ThemeToggle` and `TopNavbar` use it (TopNavbar uses the context directly).

### Server-driven data

**`useApiTable(fetchFunction, initialParams = {})`** — `src/hooks/useApiTable.js`
- Purpose: server-paginated table state. Owns `data`, `loading`, `error`, `pagination` (from the `PageResponseDTO`), and `params`; re-fetches whenever params change.
- Inputs: an async `fetchFunction(params)` returning the normalized adapter response, and optional `initialParams`.
- Outputs: `{ data, loading, error, pagination, params, handlePageChange, handleSortChange, handleFilterChange, refresh }`. `handleSortChange(field, dir)` sends `sort=field,dir` and resets to page 0; `handleFilterChange` merges filters and resets to page 0; `refresh` re-runs the fetch.
- Used by admin/staff list pages (products, plans, users, customers, policies, claims, payments) feeding `DataTable` + `PaginationBar`.

```jsx
const table = useApiTable(getAllPlansPaginated, { status: "ACTIVE" });
table.handlePageChange(page - 1); // DataTable pages call this
```

**`useApiForm(apiFunction, onSuccess)`** — `src/hooks/useApiForm.js`
- Purpose: submit orchestration for an API-backed form. Handles loading, success toast, an optional success callback, and server `fieldErrors` surfaced beside fields.
- Inputs: `apiFunction(payload)`, optional `onSuccess(data)`.
- Outputs: `{ submit(payload, customSuccessCallback?), loading, fieldErrors, setFieldErrors }`. Throws on failure so the caller can react.
- Used by create/edit forms across the app.

```jsx
const { submit, loading, fieldErrors } = useApiForm(createProduct, () => navigate("/admin/products"));
await submit(formData); // throws on server validation failure
```

### Client-side utilities

**`useClientPagination(items = [], pageSize = 9)`** — `src/hooks/useClientPagination.js`
- Purpose: slice a fully-fetched array into pages in memory; clamps the page if the array shrinks.
- Outputs: `{ page, setPage, totalPages, pageItems }`.
- Used for small customer-facing lists (e.g. products/plans grids).

**`useSearch(data = [], fields = [])`** — `src/hooks/useSearch.js`
- Purpose: case-insensitive in-memory filter across listed fields.
- Outputs: `{ searchTerm, setSearchTerm, filteredData }`.
- Used together with `useClientPagination` on small lists.

**`usePagination(initialPage = 1, initialSize = 10)`** — `src/hooks/usePagination.js`
- Purpose: pagination primitive for server queries; exposes `pageParams` (`pageNumber` = 1-based UI → 0-based API, `pageSize`, `sortDirection: "desc"`).
- Outputs: `{ currentPage, setCurrentPage, totalPages, setTotalPages, totalElements, setTotalElements, pageSize, setPageSize, pageParams }`.
- Used by `useTableState` and some manually-driven list pages.

**`useTableState({ initialSortBy, initialSortDirection, initialFilters })`** — `src/hooks/useTableState.js`
- Purpose: full table state bundle — pagination (from `usePagination`), sort (`sortBy`/`sortDirection`, toggling handler), filters, loading flag, `getQueryParams()`, and `getSrNo()` for a serial-number column.
- Outputs: `{ ...pagination, sortBy, sortDirection, handleSort, filters, handleFilterChange, getQueryParams, getSrNo, isLoading, setIsLoading }`.
- Used by list pages that build query params manually.

**`useDebounceFilters(initialFilters, onFilterChange, delay = 500)`** — `src/hooks/useDebounceFilters.js`
- Purpose: debounce typed filter inputs — local filter state, then `onFilterChange(localFilters)` fires 500 ms after the last change (skips the first render).
- Outputs: `{ localFilters, handleFilterChange, clearFilters }`.
- Used on filter toolbars to avoid a request per keystroke.

**`useDocumentTitle(title, retainOnUnmount = false)`** — `src/hooks/useDocumentTitle.js`
- Purpose: set `document.title` to `` `${title} | InsuranceFlow` `` (or just `InsuranceFlow` when empty), restoring the previous title on unmount unless `retainOnUnmount` is true.
- Used on pages to give the browser tab a per-page title.

### PDF export hooks (`src/hooks/PdfDownload/`)

All four build a jsPDF document with `jspdf-autotable`: a blue header band ("InsuranceFlow"), a section title, a two-column Field/Value table, and a confidential footer, then call `doc.save(...)`. Each is a factory returning a single download function. They read `useAuth()` to stamp "Generated By".

| Hook | File | Returned function | Filename pattern | Used on |
|---|---|---|---|---|
| `useClaimPdf` | `useClaimPdf.js` | `downloadClaim(claim)` — "Claim Summary Report" | `Claim_<claimNumber>.pdf` | Staff/Admin claim detail (`StaffClaimDetailPage`, `ClaimDetailPage`) |
| `useCustomerPdf` | `useCustomerPdf.js` | `downloadCustomer(customer)` — "Customer Details Report" | `Customer_<fullName>.pdf` | Customer/profile detail screens |
| `usePaymentPdf` | `usePaymentPdf.js` | `downloadReceipt(payment)` — "Payment Receipt" | `Receipt_<transactionReference>.pdf` | Payment history/detail screens |
| `usePolicyPdf` | `usePolicyPdf.js` | `downloadPolicy(policy)` — "Policy Summary Report" | `Policy_<policyNumber>.pdf` | Policy detail screens |

```jsx
const { downloadPolicy } = usePolicyPdf();
downloadPolicy(policy); // exports Policy_<policyNumber>.pdf client-side
```

Amounts are formatted in Indian rupees (`en-IN` locale); dates use `en-IN` formatting.

### Shared presentational component: `src/common/BentoCard.jsx`

`BentoCard` is a dashboard card: `{ icon, iconColor, title, linkTo, linkLabel, children, className, style }`. It renders a `.ip-bento-card` with a background layer, a header row (optional icon + title, optional `Link` "View all →"), and children. Used by role dashboards to host stat tiles and quick lists.

## Workflow

1. A page that needs a server table calls `useApiTable(serviceFn, params)` and wires `data`/`loading`/`pagination` into `DataTable` and `PaginationBar`.
2. A page that needs a form calls `useApiForm(serviceFn, onSuccess)` and binds `submit`/`fieldErrors`/`loading` to the form controls.
3. A small catalog list fetches once, then pipes through `useSearch` (filter) and `useClientPagination` (slice).
4. Detail pages that offer a report call the matching PDF hook and pass the fetched record.

## Best Practices

- Prefer the existing hooks over ad-hoc `useEffect` data fetching; they centralize loading/error/toast behavior.
- Use server-side pagination (`useApiTable`) for large datasets and client-side (`useClientPagination`) for small ones.
- PDF hooks keep report generation consistent and testable in one place.
